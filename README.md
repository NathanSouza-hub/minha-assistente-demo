# Minha Assistente - demo

Demo interativa do **Minha Assistente**, app de assistente pessoal: pagamentos, compromissos, viagens, medicamentos, rotina e compras, com lembretes.

**Ver a demo:** https://nathansouza-hub.github.io/minha-assistente-demo/ (já abre logada; depois de "Sair", o login é `maria@exemplo.com` / `uma-senha-forte`)

É o front-end real do projeto (React, TypeScript, Vite, Tailwind e TanStack Query) compilado com a API simulada do próprio projeto (MSW, em `web/src/mocks`). Os dados são fictícios, ficam em memória e voltam ao início quando a página é recarregada.

O back-end real (Node.js, Express, PostgreSQL, Knex, Zod e JWT) não roda nesta demo. O código completo está em https://github.com/NathanSouza-hub/Minha-Assistente
